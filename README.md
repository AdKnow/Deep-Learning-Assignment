# Deep-Learning-Assignment

## Pistachio Image Classification using CNN

This project presents the design and implementation of a Convolutional Neural Network (CNN) for classifying pistachio images. The dataset used is the Pistachio Image Dataset from Kaggle, containing images of two pistachio varieties: Kirmizi and Siirt.

The objective is to train a CNN model to distinguish between these two classes based on visual features. The network learns spatial and textural characteristics to perform classification.

### Dataset
- Source: https://www.kaggle.com/datasets/muratkokludataset/pistachio-image-dataset/data
- Classes: Kirmizi, Siirt
- Each image represents a single pistachio image sample.

### Project Structure
- **CNN Implementation.ipynb**: Main notebook containing data preprocessing, model training, evaluation, and results.
- Download dataset from kaggle

### Requirements
- Python 3.x
- NumPy  
- Matplotlib  
- scikit-learn
- Pytorch

The model achieved a train accuracy of 99% and test accuracy of 91% with the simple CNN model.    
Various data pre-processing techniques are used.    
Confusion Matrix and other Evaluation metrics are present.
